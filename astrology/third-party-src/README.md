# Harmadik fél megfelelő forráskódja

A `pyswisseph-2.10.3.2.tar.gz` a PyPI változatlan forrásarchívuma, a Python-illesztővel, a Swiss Ephemeris C-forrásával, licenceivel és fordítási fájljaival.
Az eredetet és az ellenőrzött SHA-256 lenyomatot a `manifest.json` rögzíti.
Az éles kiadás a `production/runtime-wheels.json` rögzített bináris csomagjait használja; ez az archívum biztosítja a hozzájuk tartozó megfelelő forráskódot.
